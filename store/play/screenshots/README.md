# Play Store Screenshots

Screenshots for Google Play Console upload, organized by device class.

## Device Classes

- **phone/** — Phone screenshots (portrait, typically 1080×1920 or similar)
- **sevenInch/** — 7-inch tablet screenshots
- **tenInch/** — 10-inch tablet screenshots

## Capturing Screenshots

Screenshots are captured automatically using Maestro flows. See the main [store/play/README.md](../README.md) for instructions on running the capture workflow.

## Requirements

Per [Play Console requirements](https://support.google.com/googleplay/android-developer/answer/9866151):

- **Format**: PNG or JPEG
- **Dimensions**: Min 320px, max 3840px on any side
- **Aspect ratio**: Between 16:9 and 9:16
- **File size**: Max 8 MB each
- **Quantity**: 2–8 screenshots per device class (phone required, tablets optional)

## Content Guidelines

- Show the app in use with real content (not empty states)
- Feature the most important functionality
- Use consistent branding and visual style
- Avoid text overlays (add descriptions in Play Console instead)
